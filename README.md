
# Day 21: Break and Continue in Python

This project demonstrates two important Python loop-control statements.

## Concepts Covered

- `break`: Terminates a loop immediately.
- `continue`: Skips the current iteration and moves to the next one.
- Input validation using `try-except`.
- Using `while True` to create interactive loops.

## Run the Program

```bash
python day21.py
```

## Run Unit Tests

```bash
python -m unittest -v
```

## Features

1. Interactive demonstration of `break`.
2. Demonstration of `continue` by filtering even numbers.
3. Handles invalid integer input.
4. Includes automated unit tests.
